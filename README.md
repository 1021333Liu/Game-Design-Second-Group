## 📝 作业内容

### 一、拆解分析题

主题：**"阵地与防线：塔防游戏中的空间博弈与资源调度"**

**问题 1：两种塔防范式的"空间逻辑"有何不同，对玩家防守策略有何影响？**

从"网格阵地"与"路径节点"两个维度，分析：
- **空间结构**：PvZ 的多路并进 vs KR 的曲折固定路径
- **防守思维**：均匀布局 vs 精英点位极限堆叠

**问题 2："生产型经济"（PvZ）与"掠夺型经济"（KR）如何塑造不同的玩家心智？**

- **注意力分配**：手动点选阳光如何打破"挂机感"
- **负反馈平衡**：KR 金币机制是否更易导致极端局面

---

### 二、设计题（选题 A）

**战术位移与"动态阻拦"：从静态方阵到实时博弈**

> 在 PvZ 中，植物一旦种下便无法移动（除非铲除）；而在 KR 中，兵营产生的士兵可根据玩家指令重置集结点。请为 PvZ 设计一种具有**战术重部署能力**的新型植物或防御机制。

分析方向：
- **动态响应**：可在 3×3 区域内手动指引位移的新型植物设计
- **阻拦机制**：借鉴 KR 士兵"拦截（Engage）"概念引入 PvZ 的可行性与平衡性探讨
